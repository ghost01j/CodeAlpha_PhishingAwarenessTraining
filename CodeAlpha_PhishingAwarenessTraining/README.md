# Task 2: Phishing Awareness Training

## Included
PowerPoint slides cover phishing, warning signs, fictional examples, website checks, social engineering, safe response steps, quiz questions, answer key, and references.

## How to present
1. Open `Phishing_Awareness_Training.pptx` in PowerPoint or LibreOffice Impress.
2. Present the learning objectives and warning signs.
3. Pause at the quiz slides and let learners answer before showing the answer key.
4. Replace generic reporting instructions with your organization's actual reporting process, if applicable.

## Learning objective
Help learners identify suspicious messages and use independent verification rather than interacting with risky links.
